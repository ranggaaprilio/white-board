## Installation For Development

Install White Board with bun

```bash
  cd white-board
  bun install
  bun run dev
```

In another terminal ,please execute :

```bash
  cd white-board
  npx convex dev
```

## Tech Stack

**Client:** NextJs,Nodejs v.21,Typecript

**Server:** Convex

**AuthService:** Clerk

## Environment Variables

To run this project, you will need to add the following environment variables to your .env file

`CONVEX_DEPLOYMENT` (generated by convex after running npx convex dev)

`NEXT_PUBLIC_CONVEX_URL` (generated by convex after running npx convex dev)

`NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY` (copy from API key Section on Clerk dashboard
)

`CLERK_SECRET_KEY`(copy from API key Section on Clerk dashboard
)
